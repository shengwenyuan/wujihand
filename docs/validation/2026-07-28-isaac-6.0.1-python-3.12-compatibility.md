## 结论

当前基础 package、五层解析、domain 和 transport 已在 Python 3.11/3.12 双版本通过
回归；固定 Wuji Hand 2 五层 Session 已在 Isaac Sim 6.0.1.0 / Python 3.12.3 中完成
headless 场景启动、8 帧 stepping、关节/限位检查和截图，退出码为 `0`。

NV-0/0A 判定为 `PROCEED`，允许进入 NV-0B。兼容结论的边界是：

- 基础 package 支持 Python `>=3.11,<3.13`。

- Isaac 6.0.1 使用其 vendor Python 3.12 环境，从受控 checkout 加载项目源码；不把
  项目 NumPy/SciPy 约束安装进 vendor venv。
- 本记录只证明现有固定 Hand 2 Session 的起始兼容性；新增 Isaac API 每个里程碑仍需
  独立 smoke。

## NV-1 五层边界

NV-1 定义为 VIVE input adapter 的只读组件/HIL 资格验证，不创建虚假的 Isaac Session，
不把 Tracker 放入 Asset/Backend Binding。NV-3 出现真实 NERO Isaac consumer 后，由
五层 Session 作为目标组合根，并通过 DeploymentSpec 编排 VIVE producer。

若未来要求 NV-1 自身成为正式多进程部署运行时，应先引入 DeploymentSpec ADR，而不是
借用与 VIVE 无关的 Session。
