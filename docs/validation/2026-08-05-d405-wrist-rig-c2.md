## C2 mount collision

左右 mount 各 author 14 个 compound child shapes，共 28 个：6 个 box 与 8 个 capsule。
桁架空隙没有被单一 convex hull 填满。所有 shape 都附着到既有 Hand 2 base rigid body；
wrist-rig subtree 内新增 rigid body、MassAPI、joint 和 articulation root 数量均为零。
D405 housing box collision 仍为零。

左、右、双侧三次 C2 均通过 rest、慢速 close、grasp hold、慢速 open、final rest。双侧
结果的 q7/q20 最大稳态误差为 `0.043011/0.189439 rad`，最大 hold drift 为
`0.001140 rad`，最大 hand-base 位移漂移为 `0.0538 mm`；无 nominal mount contact、深穿透
或跨侧 contact。每侧 35 个 body 的 runtime mass/COM/principal axes/inertia 与对应 C1
baseline 在 `1e-12` 绝对容差内一致。

稳定性快照完成后，隔离的左右 kinematic probe 分别插入两侧 mount outer rail，均得到
实际负 separation contact。该 smoke 只证明 mount collision 参与 PhysX 求解，不进入主
轨迹的穿透与姿态漂移判据。
